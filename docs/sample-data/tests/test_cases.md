# Earth & Hub Test Cases

| Test Case | Input | Expected Result |
|---|---|---|
| Open website | Open application | Home page loads successfully |
| View rural information | Select a category | Relevant information is displayed |
| Search resources | Enter a resource | Matching information is displayed |
| Submit issue | Enter a community issue | Issue is recorded successfully |
| Track issue | Enter issue details | Issue status is displayed |
| Language selection | Select Tamil/English | Selected language is displayed |
| View schemes | Select government schemes | Available schemes are displayed |
| View opportunities | Select education/jobs | Relevant opportunities are displayed |

## Testing Approach

The application can be tested using functional testing to verify that each major feature works as expected. Additional testing will be performed as new features and database functionality are added.
